#  Lua Game Development Studies

Repository dedicated to studying and practicing **Lua programming** with a focus on **game development**.

## About

This project is part of my learning journey into game development using **Lua**, primarily with the **LÖVE (Love2D) framework**.

The objective is to build practical projects that strengthen my understanding of:

- Game logic
- Input systems
- UI development
- State management
- Object-oriented concepts in Lua
- Basic game architecture

## Technologies Used

- Lua
- LÖVE (Love2D)
- Git & GitHub
